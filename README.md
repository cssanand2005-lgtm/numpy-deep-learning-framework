\# 🧠 Custom Deep Learning Framework in Pure NumPy



A PyTorch-like deep learning library built completely from scratch using \*\*only NumPy\*\*. 



\## 🌟 Features

\- Base `Layer` abstraction class (`Linear`, `ReLU`).

\- Custom `SGD` optimizer and `SoftmaxCrossEntropy` loss.

\- `Sequential` container for modular layer stacking.

\- Interactive Streamlit Web Interface.
